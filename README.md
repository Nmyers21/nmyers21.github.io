# Noah L. Myers — Portfolio

Static GitHub Pages portfolio with responsive dark styling and progressive animation.

- `index.html`: experience, projects, skills, resume previews and downloads
- `capstone.html`: WGU academic ransomware case study
- `ai-redteam.html`: AI evaluation prototype writeup
- `soc-analysis.html`: simulated Windows event analysis writeup
- `assets/style.css`: responsive styles, reduced-motion support and print layout
- `assets/site.js`: scroll reveals, back-to-top behavior and print actions
- `assets/*.pdf`: user-supplied resumes
- `assets/*-writeup.txt`: downloadable project summaries

Preview with `python3 -m http.server 8000`. No build step required. Content and downloads remain available without JavaScript. Writeup print buttons open the browser print dialog, which supports saving as PDF.
